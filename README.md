# 🤖 AI Skill Gap Analyzer

## 📌 Project Overview

**AI Skill Gap Analyzer** is a beginner-friendly web application that helps users identify the skills they already have and the skills they need to develop for a selected career role.

The application compares the user's current skills with the required skills for different job roles and provides a **skill match percentage, missing skills, learning roadmap, and recommended projects**.

## 🎯 Objective

The main objective of this project is to help students and job seekers understand their current skill level and identify the skills they need to improve for their desired career.

## ✨ Features

* 👤 User name input
* 💼 Multiple job role selection
* 🛠️ Current skill selection
* 📊 Skill match percentage
* ✅ Matching skills identification
* ❌ Missing skills identification
* 📚 Personalized learning roadmap

## 🧠 How It Works

The application follows these basic steps:

```text
User Input
    ↓
Select Target Job Role
    ↓
Select Current Skills
    ↓
Compare Required Skills
    ↓
Calculate Skill Match
    ↓
Identify Missing Skills
    ↓
Generate Learning Roadmap
    ↓
Recommend Projects
```

## 📈 Skill Match Calculation

The application calculates the skill match percentage based on the number of required skills that match the user's selected skills.

```text
Skill Match % =
(Matching Skills / Required Skills) × 100
```

## 💾 LocalStorage

The project uses browser **LocalStorage** to save the user's latest skill analysis.

This allows the latest analysis to remain available even after refreshing the page.
